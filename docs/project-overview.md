# Odoo 19.0 Project Overview

## What is Odoo?

Odoo is a comprehensive, open-source ERP (Enterprise Resource Planning) suite of business applications. It provides an integrated platform for managing all aspects of business operations, from CRM and sales to inventory, manufacturing, and accounting.

### Technical Features

- **Modular Architecture**: 600 independent, installable modules
- **Custom ORM**: Built-in object-relational mapper
- **Multi-Company**: Multiple companies in single database
- **Multi-Currency**: Full currency support with exchange rates
- **Localization**: 100+ country-specific tax/accounting modules
- **API**: JSON-RPC and XML-RPC interfaces
- **Web Framework**: Full-stack with OWL frontend framework

## Getting Started

### Quick Start (Development)

```bash
# Clone
git clone https://github.com/odoo/odoo.git
cd odoo

# Setup
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt

# Run
./odoo-bin -d mydb -i base
```
